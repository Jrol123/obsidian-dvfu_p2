# Принятие решений в условиях неопределённости
## Основные понятия
Принятие решений в условиях определённости (уверенности)
	Ситуация, когда лицо, принимающее решение (ЛПР) точно знает все возможные исходы для каждого варианта действий.
	Нет случайных факторов, неполноты информации. Поэтому последствия решения однозначно предсказуемы.
	Используются следующие методы: ранжирование, группировка критериев, метод равномерного сжатия, сумма отклонений

## Метод ранжирования
Систематическая процедура, упорядочения альтернатив по предпочтительности для выбора наилучшего варианта решения.
Выбор альтернативы осуществляется на основе максимизации суммы первых, вторых и т.д. мест или минимизации суммы мест каждой из альтернатив
$f^{*}\left( a_{i} \right) \sum \limits_{ j=1 }^{ n }r _{j}\left( a_{i} \right) \to \max \quad\left( 1 \right)$
$f^{*}\left( a_{i} \right) \sum \limits_{ j=1 }^{ n }r _{j}\left( a_{i} \right) \to \min \quad\left( 2 \right)$
$j$ - порядковый номер оценочного критерия
$i$ - порядковый номер альтернативы
$a_{i}$ - альтернативный вариант (совокупность управленческих решений)
$r_{j}\left( a_{i} \right)$ - ранг (место) критерия
$f^{\star}\left( a_{i} \right)$ - интегральная функция полезности (функция цели)

## Метод группировки критериев
При решении многокритериальных задач различные оценочные критерии приводятся к одной единице измерения в виде одной безразмерной величины.
Процесс приведения критериев к единому виду называется нормализацией.
Нормализация бывает в виде следующих методов
### Метод естественной нормализации
Преобразование текущего параметра на основе сравнения его значения с худшим параметром относительно интервала изменений.
$f_{j}^{\star} \left( a_{i} \right) = \dfrac{f_{j}\left( a_{i} \right) - f_{j}^{\min}\left( a \right)}{f_{j}^{\max}\left( a \right) - f_{j}^{\min}\left( a \right)}$
$f^{\star}_{j}\left( a_{i} \right)$ - нормализованное значение критерия
$f_{j}\left( a_{i} \right)$ - текущее значение параметра
$f_{j}^{\max}\left( a \right)$ - максимальное значение параметра
$f_{j}^{\min}\left( a \right)$ - минимальное значение параметра

### Метод нормализации сравнения
оценка соотношения текущего результат и лучшего (худшего) значения критерия
$f_{j}^{\star}\left( a_{i} \right) = \dfrac{f_{j}\left( a_{i} \right)}{f_{j}^{\max\left( \min \right)}\left( a \right)}$

### Метод нормализации осреднения
Сравнение текущего результата со средним значением критерия или суммой всех критериев
$f_{j}^{\star}\left( a_{i}  \right) = \dfrac{f_{j}\left( a_{i} \right)}{\sum f_{j}\left( a_{i} \right) / n}$
$f_{j}^{\star}\left( a_{i} \right) = \dfrac{f_{j}\left( a_{i} \right)}{\sum f_{j}\left( a_{i} \right)}$

Для выбора альтернативы (принятия решения) методом группировки критериев используются следующие оценочные критерии
- Равномерная оптимальность
	- Лучшей считается альтернатива, которая имеет максимальную сумму отдельных значений параметров целевой функции. 
		$f^{\star}\left( a_{i} \right) = \sum \limits_{ j = 1 }^{ n }f_{j}^{\star}\left( a_{i} \right) \to \max$
- Справедливый компромисс
	- Выбор наилучшей альтернативы на основе максимального значения произведения анализируемых критериев
		$f^{\star}\left( a_{i} \right) = \prod \limits_{ j = 1 }^{ n }f_{j}^{\star}\left( a_{i} \right) \to \max$
- Свёртывания критериев
	- Каждому из анализируемых критериев присваивается весовой коэффициент $\alpha _{j}$, отражающий степень значимости текущего показателя
		$f^{\star}\left( a_{i} \right) = \sum \limits_{ j = 1 }^{ n }\alpha_{j}f^{\star}_{j}\left( a_{i} \right) \to \max$

# Принятие решений в условиях неопределённости
В большинстве задач возникает необходимость принятия решений, когда ключевые параметры задачи неизвестны. В этом случае решение принимается в условиях неопределённости, которое описывается некоторым ограниченным множеством, возможных состояний внешней среды (гипотез).
Для решения таких задач используется метод платёжной матрицы.
Платёжная матрица - способ структурирования исходной информации, который обеспечивает нахождение оптимального плана (альтернативы) в условии неопределённости. При этом используются следующие оценочные критерии:
- Гарантированный результат
- Принцип оптимизма
- Принцип среднего значения
- Комбинированный принцип

Оценочный критерий
Прицнип гарантированный результат
	Этот критерий основан на выборе альтернативы, которая обеспечивает наилучший результат из самых неблагоприятных
	$f_{ij}^{\star}\left(a_{i}\right) = \max \min \{  f_{j}\left(a_{i}\right) \}$
Принцип оптимизма
	Получение максимального результата из наиболее благоприятных
	$f_{ij}^{\star}\left(a_{i}\right) = \max \max \{  \left( f_{j}\left(a_{i}\right) \right) \}$
Принцип оптимизма
	Получение максимального результата из наиболее благоприятных
	$f_{ij}^{\star}\left(a_{i}\right) = \max \max \{  \left( f_{j}\left(a_{i}\right) \right) \}$
Принцип среднего значения (критерий Лапласа)
	Выбор лучшего решения из возможных средних. Используется, когда гипотезы являются равновероятными
	$f_{ij}^{\star}\left(a_{i}\right) = \max \left\{   \dfrac{\sum \limits_{ j = 1 }^{ n } f_{ij}\left( a \right)}{n}  \right\}$
	Используется в основном тогда, когда руководство не может отдать предпочтение одной из гипотез
Гарантированный принцип
	Сочетание принципа гарантированного результата и принципа оптимизма
	$f_{ij}^{\star}\left( a \right) = \max \left[ \alpha \min \left\{ f_{ij}\left( a \right) \right\} + \left( 1 - \alpha \right) \max \left\{ f_{ij} \left( a \right) \right\} \right]$
	$\alpha$ - коэффициент риска, характеризующий склонность человека к проведению рискованных решений. $0 \leq \alpha \leq 1$

# Принятие решений в условиях риска
Выбор наилучшей альтернативы с учётом вероятности наступления гипотез.
В качестве оценочного критерия используется математическое ожидание по каждой альтернативе.
$f_{ij}^{\star}\left( a \right) = p_{i}f_{ij}\left( a_{i} \right) \to \max$
$p_{i}$ - вероятность $i$-й гипотезы.
