1. Installation
------------------------------------------------------------

As a 'full' product from the CD :

Insert the CD into the CD ROM drive then using either the Windows Explorer
or Start/Run option, browse to the CD drive letter (i.e. D:) and run setup.exe. 
Then follow the instructions on the screen.


2. Upgrading from a Previous Version
----------------------------------------------------------- 

Although you can have multiple versions of BPwin on your system, it is 
not recommended for this release since models may not be forward 
compatible (That is that BPwin 2.5 cannot open models saved in 
BPwin 2.5 Service Pack 3). You should either install the patch to 
upgrade the current BPwin version OR uninstall the previous BPwin
version before installing this version/patch level.

NOTE: the Installation program will detect the presence of a 
      previous BPwin installation and ask if you wish to uninstall.


3. Advisory Notes
-----------------------------------------------------------

*  BPwin 2.5 Service Pack 3 is a 32 bit version only and has been 
   validated on:  Windows 95, Windows 98, Windows 2000, and  Windows NT 4.0.
   
*  BPwin 2.5 Service Pack 3 includes support for ModelMart 3.0.2 SP2 
   and ERwin 3.5.2 SP3 - although it has been tested with other 
   releases of 3.02 / 3.5.2, Computer Associates recommends that all be upgraded
   to the highest Service Pack level.

*  Models saved with this version of BPwin cannot be opened with 
   earlier versions of BPwin. If you need to use an earlier version 
   of BPwin for some models, we recommend that you keep these models 
   in a separate directory.

*  There is a minor difference in appearance of the Arrow Data 
   dialog between printed documentation and actual software.
   We inadvertently omitted the icons for Entities and Attributes 
   in printed documentation. The icons are visible in the Arrow Data 
   dialog in the software.

*  This service pack includes certain improvements to ModelMart. However, 
   the actual modifications were applied to BPwin (and ERwin) directly.
   For this reason, we have not provided a separate service pack for ModelMart.
   After you install BPwin 2.5 SP3, you can continue to use the current version
   of ModelMart 3.0.2 (Build 436+).


   Known Issues at time of production:
   ----------------------------------
   This release (BPwin 2.5 SP3) is a later release of BPwin 2.5 that 
   includes a number of fixes.


4. Sources of Information
-------------------------

Information about installing and using BPwin is provided in the
following documents:

BPwin New Features Guide.
Provides information about the new features in BPwin version 2.5. 
It also contains installation information.

BPwin Online Help. 
Provides full instructions on the major features of 
BPwin including the multi-user features provided by ModelMart. 
Press F1 for context sensitive help on any dialog in BPwin.

If you need information, you can reference the Frequently Asked
Questions (FAQ) document, which is installed with BPwin
and has its own icon. FAQ documents are also posted on our
web site at http://www.cai.com. Choose Support and choose 
Former Platinum Support under Support Services, and then 
choose Resources by Product Name, locate BPwin and then choose
FAQs from the Resources Available list (need a password to access).

Documentation
-------------

If you are a new BPwin user and you purchased BPwin 2.5,
you will receive several printed manuals. Some of the information
in those manuals may not be up to date because they were written for
earlier versions such as BPwin 2.0. However, the BPwin Online 
Help, which is available on the Help menu, includes the 
most current information about this release.


If you previously purchased BPwin 2.0 and you are upgrading 
to BPwin 2.5, you will receive the BPwin Version 2.5 New Features Guide, 
which describes the features that were added in BPwin 2.5. 
Most of the information is this document is current but you should 
use the BPwin Online Help system for any changes in BPwin since this 
book was published.

5. What's New!
--------------

* On-line tutorial.

* Removal of 32k limit on primary modeling objects.

* The spelling checker now allows for additional default 
  languages. Included languages are American English, French,
  German, Italian, and Spanish.

* Inclusion of off page references for IDL export/import.

* The Cost Editor has now been incorporated into the 
  Activity Property Sheet as the Costs tab. Functionality 
  is still the same.


6. Contacting Computer Associates Technical Support
------------------------------------------------------------

If you need technical support, you can visit the 
Computer Associates Technical Support web site at 
http://support.cai.com/. 

* For online support, select Star TCC from the Support Resources 
  list. 

* For telephone support, select Calling CA for Support from the 
  Support Services list and find the telephone number for your 
  calling area.


When you contact Computer Associates Technical Support, please have 
the following information ready for the support analyst:

* The serial number of the product you are using (the serial 
  number can be found on the right sleeve of the compact
  disc holder).

* The version number and the build number of the product
  (available from the About menu option on the Help menu).

* The operating system or platform (for example,
  Windows NT 4.0), as well as any service pack applied.

* If you are using ModelMart, the database on which your
  ModelMart resides.

* A description of the problem, the steps that led to
  the problem, and any error messages.
