# Условие
Есть фирма с двумя видами продукции. Эта продукция реализуется на рынке. Есть ограничения, накладываемые на рынок сбыта и на склад.

Решение задачи заключается в:
	учитывая ограничения по рынку и складу организовать производство так, чтобы количество продуктов 1 и 2 выдавало максимальную прибыль

# Решение
$x_{1}$ - Продукт 1 (A)
$x_{2}$ - продукт 2 (B)

Функция цены F
$F = 3000x_{1} + 4000x_{2} \to \max$

Ограничения по складу
$\begin{cases}3x_{1} + 2x_{2} \leq 7 \\ 3x_{1} + 3x_{2} \leq 9\end{cases}$

Ограничения по 
$\begin{cases}x_{1}-x_{2}\leq 1 \\ x_{1}\leq 3\end{cases}$

$\begin{cases}x_{1} \geq 0 \\ x_{2}\geq 0\end{cases}$
