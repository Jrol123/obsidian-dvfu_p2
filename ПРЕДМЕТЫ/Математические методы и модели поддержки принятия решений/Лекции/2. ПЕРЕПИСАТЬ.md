Целевая функция - функция, связывающая цель с управляемыми переменными. Или это вещественная или целочисленная функция нескольких переменных, которые подлежат оптимизации

задачи линейного программирования (ЗЛП) - это задача оптимизации (нахождение наилучшего решения), в которой требуется найти максимум или минимум (max\min), линейной ЦФ при линейных ограничениях и неотрицательности переменных

Типы ЗЛП:
1. каноническая форма - все ограничения представленны в виде равенств
2. Стандартная форма - ограничения даны в виде неравенств
3. Общая форма - комбинация равенств и неравенств

Основной формой является стандартная:
Задается ЦФ F(x), F, f(x), f 
F(x)=c1x1+c2x2+...+CnXn стремится (стрелка) max(min)
X-неизвестная переменная
С - коэфициенты

При ограничениях a11x1+a12x2+...+a1nxn<=b1;

am1x1+am2x2+...+amnxn<=bm;

x1>=0, x2>=0,...,xn>=0

Где используются задачи ЛП:
при оптимизации, задача о рационе, задача о рюкзаке (ранце), в экономике и ИКД, размещения, различные информации, web дизайн сайтов.

Решение ЗЛП симплекс методом.

Симплекс - метод - общий метод решения задач линейного программирования. 1953 год, Джордж Данциг - 3 основные теоремы, нобелевка. Основной метод в ЛП
Метод основан на численном решении систем линейного уравнения методом Крамера.
Для наглядности и простоты метод крамера преставляют в виде таблицы, по определенному алгоритму.
Алгоритм решения ЗЛП включает в себя:
1. Заданную математическую модель (ММ) ЗЛП необходимо представить в канонической форме. Для этого max ЦФ представить как min (умножить на -1) и ввести свободные переменные.
2<3
2+1=3
3=3
xi - свободная переменная

3>2
3-1=2
2=2

2. Составляем исходную симплекс таблицу.
в 1м столбце таблицы записываются вектора входящие в базис.
во 2м столбце - коэфициенты Ci ЦФ
3й столбец - компоненты опорного плана. в конце этого столбца - величина Z0 = m summ i=1 cixi
далее идут столбцы соответствующие всем векторам Ai.
в дополнительной строке сверху записываются коэфициенты Ci ЦФ. В дополнительной строке снизу - разности Zj-Cj= m(сверху) summ (знак) i=1 (снизу) CiXij-Cj

3. Просматривается дополнительная строка снизу.
если Zj-Cj<=0, то полученный план решения будет оптимальным. На этом решение заканчивается. В противном случае переходит к следуещему этапу.

4. В нижней дополнительной строке выбирается столбец Zj-Cj>0, то выбирается столбец с максимальным значением, которая называется направляющим. Его вводят в базис следующей таблицы. В этом столбце выбирается элемент с положительным значением Xij>0, который называется определяющим. Если в этом столбце несколько Xij, то выбираем тот, который соответствует формуле. Тетта0=min Xi\Xij. Строка соответствующая этому элементу называется направляющая. В нее записывается новое значение Ai, входящее в базис

5. Составляется новая симплекс таблица, в которой все компоненты пересчитываются из исходной симплекс таблицы по правилам: для направляющей строки новый элемент равен старый элемент \ Xij;
правила для всех остальных клеток таблицы перерасчет делается по правилу: новый элемент равен старый элемент (предыдущая симплекс таблица) минус элемент новой направляющей строки, стоящий в этом же столбце * на элемент старого направляющего столбца, стоящий в этой же строке.

далее иттерации продолжаются до тех пор, пока не будет получено условие оптимальности Zj-Cj<=0 для нижней дополнительной строки
