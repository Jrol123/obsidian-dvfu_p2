# Решение матричных игр в чистых стратегиях
Рассмотрим игру $m\cdot n$ с платёжной матрицей $P=\left( a_{ij} \right)$.
Выбирая стратегию $A_{i}$, игрок $A$ должен учитывать, что игрок $B$ ответит на неё стратегией $B_{j}$, при которой выигрыш игрока $A$ будет наименьшим, т. е. игрок $A$ должен выбрать $\max  \min$ стратегию.
$\alpha = \max \min a_{ij}$ *Нотация преподавателя, не ошибка*
где $\alpha$  - нижняя цена игры- наименьший выигрыш игрока $A$ при всех возможных стратегиях игрока $B$ - гарантированный выигрыш $A$ при любых стратегиях игрока $B$.

Игрок $B$ будет стремиться к тому, чтобы обеспечить себе наименьший проигрыш при любых стратегиях игрока $A$, поэтому он будет использовать $\min \max$ стратегию
$\beta = \min \max a_{ij}$
где $\beta$ - верхняя цена игры - гарантированный проигрыш игрока $B$.


Пара чистых стратегий, $a_{i}, b _{j}$ даёт оптимальное решение игры тогда и только тогда, когда соответствующий ей элемент $a_{i, j}$ является одновременно наибольшим в своём столбце и наименьшим в своей строке.
Такая ситуация называется **седловой точкой**, а игра, при которой $\alpha = \beta$ называется игрой с седловой точкой.

Таким образом, решение игры в чистых стратегиях существует тогда и только тогда, когда платёжная матрица имеет седловую точку.

## Пример
### Условие
Определить верхнюю и нижнюю цену игры и соответствующие им стратегии для игры заданной следующей платёжной матрицей
$$
P = \begin{pmatrix}
0 & -1 & -2 \\
1 & 0 & -1 \\
2 & 1 & 0
\end{pmatrix}
$$

### Решение
Составим вспомогательную таблицу

|                           | $B_{1}$ | $B_{2}$ | $B_{3}$                                   | $\alpha _{i} = \min a_{ij}$ | $\alpha = \max \alpha_{i}$ |
| ------------------------- | ------- | ------- | ----------------------------------------- | --------------------------- | -------------------------- |
| $A_{1}$                   | 0       | -1      | -2                                        | -2                          |                            |
| $A_{2}$                   | 1       | 0       | -1                                        | -1                          |                            |
| $A_{3}$                   | 2       | 1       | <mark style="background:#ff4d4f">0</mark> | 0                           | 0                          |
| $\beta_{j}=\max a_{ij}$   | 2       | 1       | 0                                         |                             |                            |
| $\beta = \min \beta _{j}$ |         |         | 0                                         |                             |                            |
