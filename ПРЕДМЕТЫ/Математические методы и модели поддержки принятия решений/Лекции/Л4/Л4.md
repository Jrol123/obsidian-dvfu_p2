# Решение матричных игр в чистых стратегиях
Рассмотрим игру $m\cdot n$ с платёжной матрицей $P=\left( a_{ij} \right)$.
Выбирая стратегию $A_{i}$, игрок $A$ должен учитывать, что игрок $B$ ответит на неё стратегией $B_{j}$, при которой выигрыш игрока $A$ будет наименьшим, т. е. игрок $A$ должен выбрать $\max  \min$ стратегию.
$\alpha = \max \min a_{ij}$ *Нотация преподавателя, не ошибка*
где $\alpha$  - нижняя цена игры- наименьший выигрыш игрока $A$ при всех возможных стратегиях игрока $B$ - гарантированный выигрыш $A$ при любых стратегиях игрока $B$.

Игрок $B$ будет стремиться к тому, чтобы обеспечить себе наименьший проигрыш при любых стратегиях игрока $A$, поэтому он будет использовать $\min \max$ стратегию
$\beta = \min \max a_{ij}$
где $\beta$ - верхняя цена игры - гарантированный проигрыш игрока $B$.


Пара чистых стратегий, $a_{i}, b _{j}$ даёт оптимальное решение игры тогда и только тогда, когда соответствующий ей элемент $a_{i, j}$ является одновременно наибольшим в своём столбце и наименьшим в своей строке.
Такая ситуация называется **седловой точкой**, а игра, при которой $\alpha = \beta$ называется игрой с седловой точкой.

Таким образом, решение игры в чистых стратегиях существует тогда и только тогда, когда платёжная матрица имеет седловую точку.

## Пример
### Условие
Определить верхнюю и нижнюю цену игры и соответствующие им стратегии для игры заданной следующей платёжной матрицей
$$
P = \begin{pmatrix}
0 & -1 & -2 \\
1 & 0 & -1 \\
2 & 1 & 0
\end{pmatrix}
$$

### Решение
Составим вспомогательную таблицу

|                           | $B_{1}$ | $B_{2}$ | $B_{3}$                                   | $\alpha _{i} = \min a_{ij}$ | $\alpha = \max \alpha_{i}$ |
| ------------------------- | ------- | ------- | ----------------------------------------- | --------------------------- | -------------------------- |
| $A_{1}$                   | 0       | -1      | -2                                        | -2                          |                            |
| $A_{2}$                   | 1       | 0       | -1                                        | -1                          |                            |
| $A_{3}$                   | 2       | 1       | <mark style="background:#ff4d4f">0</mark> | 0                           | 0                          |
| $\beta_{j}=\max a_{ij}$   | 2       | 1       | 0                                         |                             |                            |
| $\beta = \min \beta _{j}$ |         |         | 0                                         |                             |                            |

$\alpha = \beta = 0  \quad \nu = 0$ (цена игры, значение седловой точки)

Из вспомогательной таблицы видно, что отклонение первого игрока от оптимальной стратегии уменьшает его выигрыш, а отклонение второго игрока от его оптимальной стратегии увеличивает проигрыш

# Решение матричных игр в смешанных стратегиях
При отсутствии седловой точки решение матричной игры приводит к необходимости использовать смешанные стратегии, т.е. чередовать чистые стратегии с определёнными частотами.
**Смешанная стратегия** - случайная величина, значениями которой являются чистые стратегии игрока, т.е. задание смешанной стратегии заключается в  указании тех вероятностей, с которыми выбираются его чистые стратегии.
$S_{A}$ - смешанная стратегия игрока $A$
$S_{A} = \left( p_{1}, p_{2}, \ldots, p_{m} \right)$
$S_{B} = \left( q_{1}, q_{2}, \ldots, q_{n} \right)$
$p_{i}$ - вероятность применения игроком $A$ чистой стратегии $A_{i}$
$q_{j}$ - вероятность применения игроком $B$ чистой стратегии $B_{j}$


Примечание: Матричные игры $2\times 2$ могут решаться аналитически или графически, а матричные игры $m \times n$ - сведением к задаче линейного программирования.

# Решение матричных игр $m \times n$ сведением их к задаче ЛП
Имеется матричная игра $m \times n$ без седловой точки $P = \{ a_{ij} \}$. 
В соответствии основной теорией матричных игр, если платёжная матрица не имеет седловой точки, то имеется пара оптимальных смешанных стратегий $S_{A}^{*}$ и $S_{B}^{*}$ применение которых обеспечивает получение цены игры $\nu$.
Для игрока $A$ выигрыш будет не меньше цены игры, заданной следующей системой неравенств $\begin{cases} a_{11} p_{1} + a_{21} p_{2} + \ldots + a_{m1} p_{m} \geq \nu \\  \ldots \\  a_{1n}p_{1} + a_{2n}p_{2} + \ldots a_{mn}p_{m} \geq \nu \end{cases} \quad\left( 1 \right)$
Разделим левую и правую части  каждого из неравенств $\left( 1 \right)$ на $\nu$ и введём следующие обозначения:
$x_{1} = \dfrac{p_{1}}{\nu}; \quad x_{2}=\dfrac{p_{2}}{\nu};\ldots$

$\begin{cases} a_{11} x_{1} + a_{21} x_{2} + \ldots + a_{m1} x_{m} \geq 1 \\  \ldots \\  a_{1n}x_{1} + a_{2n}x_{2} + \ldots a_{mn}x_{m} \geq 1 \end{cases} \quad\left( 2 \right)$

$x_{1} + x_{2} + \ldots + x_{m} \to \max$ - Значение целевой функции. Игрок стремится максимизировать выигрыш.
Учитывая, что $p_{1} + p_{2} + \ldots + p_{m} = 1$, тогда выражение для целевой функции можно переписать в следующем виде:
$F\left( x \right) = Z = x_{1} + x_{2} + \ldots + x_{m} = \dfrac{1}{\nu} \to \min \quad\left( 3 \right)$
$\dfrac{p_{1}}{\nu} + \dfrac{p_{2}}{\nu} + \ldots + \dfrac{p_{m}}{\nu} = \dfrac{1}{\nu}$


Решая задачу линейного программирования для целевой функции $\left( 3 \right)$ и ограничений $\left( 2 \right)$ можно найти цену игры $\nu$ и оптимальную стратегию игрока $S_{A}^{*}$ по формулам
$\nu = \dfrac{1}{\sum x_{i}};\ p_{i} = x_{i}\nu$




Для игрока $B$ стратегии $S_{B}^{*}$ находятся аналогичным образом, но с учётом того, что он использует минмакс стратегию. Тогда систему ограничений игрока $B$ можно описать в следующем виде.
$\begin{cases} a_{11} q_{1} + a_{21} q_{2} + \ldots + a_{m1} q_{m} \leq \nu \\  \ldots \\  a_{1n}q_{1} + a_{2n}q_{2} + \ldots a_{mn}q_{m} \leq \nu \end{cases} \quad\left( 4 \right)$
Разделим левую и правую части  каждого из неравенств $\left( 4 \right)$ на $\nu$ и введём следующие обозначения:
$y_{1} = \dfrac{q_{1}}{\nu}; \quad y_{2}=\dfrac{q_{2}}{\nu};\ldots$

$\begin{cases} a_{11} y_{1} + a_{21} y_{2} + \ldots + a_{m1} y_{m} \leq 1 \\  \ldots \\  a_{1n}y_{1} + a_{2n}y_{2} + \ldots a_{mn}y_{m} \leq 1 \end{cases} \quad\left( 5 \right)$
$y_{1} + y_{2} + \ldots + y_{m} \to \min$ - Значение целевой функции. Игрок стремится минимизировать проигрыш.
Учитывая, что $q_{1} + q_{2} + \ldots + q_{m} = 1$, тогда выражение для целевой функции можно переписать в следующем виде:
$F\left( x \right) = L = y_{1} + y_{2} + \ldots + y_{m} = \dfrac{1}{\nu} \to \max \quad\left( 6 \right)$
$\dfrac{q_{1}}{\nu} + \dfrac{q_{2}}{\nu} + \ldots + \dfrac{q_{m}}{\nu} = \dfrac{1}{\nu}$


Решая задачу линейного программирования для целевой функции $\left( 6 \right)$ и ограничений $\left( 5 \right)$ можно найти цену игры $\nu$ и оптимальную стратегию игрока $S_{B}^{*}$ по формулам
$\nu = \dfrac{1}{\sum y_{i}};\ q_{i} = y_{i}\nu$


Анализ полученных выражений для игрока $A$ и $B$ показывает, что для решения матричной игры в смешанных стратегиях используется двойственная задача ЛП

# Алгоритм решения матричной игры
Исключить из платёжной матрицы заведомо невыгодные стратегии, которые для игрока $A$ соответствуют строкам заведомо меньшими по сравнению с элементами других строк и наоборот для игрока $B$
При отсутствии седловой точки решение находится в смешанных стратегиях.
4. Отрицательные значения элементов платёжной матрицы заменить на положительные. Для этого к каждому её элементу прибавить число $\gamma = \left| \min a_{ij} \right| + 1$. При получении ответа это число нужно вычесть из $\nu$


### Пример
2 отрасли осуществляют капитальные вложения в 3 фирмы, стратегии которых заключаются в финансировании объектов.
Полученные прибыли выражаются следующей матрицей
$$
P = \begin{pmatrix}
-1 & 1 & 6 \\
5 & 2 & -3 \\
-2 & 4 & 5
\end{pmatrix}
$$
Величина прибыли первой отрасли считается такой же величиной убытка для второй отрасли.
#### Находим $\alpha$ и $\beta$
$\alpha = \max\left( -1, -3, -2 \right) = -1$
$\beta = \min\left( 5, 4, 6 \right) = 4$
$\alpha \neq \beta$
Седловой точки нет.
Решаем задачу в смешанных стратегиях.
Для сведения матричной игре к задаче ЛП все её элементы должны быть положительными.
$\gamma = \left| -3 \right| + 1 = 4$
$$
P' = \begin{pmatrix}
3 & 5 & 10 \\
9 & 6 & 1 \\
2 & 8 & 9
\end{pmatrix}
$$

Стратегия для игрока $A$
$F\left( x \right) = x_{1} + x_{2} + x_{3} \to \min$

Рассматриваем первую стратегию игрока $B$
$$
\begin{cases}
3x_{1} + 9x_{2} + 2x_{3} \geq 1 \\
5x_{1} + 6x_{2} + 8x_{3} \geq 1 \\
10x_{1} + 1x_{2} + 9x_{3} \geq 1 \\
x_{i} \geq 0
\end{cases}  \quad \left( A \right)  
$$
Для решения полученной системы $A$ используем excel.

В результате получили $x_{1} = 0.0787; x_{2}=0.0816; x_{3}=0.0146$
$\nu=\dfrac{1}{\sum x_{i}} = \dfrac{1}{0.1749}=5.7167$
$p_{1} = 0.0787 \cdot 5.7167 = 0.45; p_{2}=0.47; p_{3} = 0.08$
$S_{A}^{*} = \left( p_{1}; p_{2}; p_{3} \right); \nu = 5.7167-4=1.7167$

Составим двойственную задачу для $B$
$L = y_{1} + y_{2} + y_{3} \to \max$

y_{i} \geq 0
\end{cases}
$$
